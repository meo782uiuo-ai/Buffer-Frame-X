# Buffer Frame (v0.2.0)
Mod de Geode que corrige clicks tempranos (hasta 96 ticks configurables). Solo para practica: da ban en rankeds.

## Uso
- Boton del pincho en el menu principal o en la pausa -> menu con Etapas, Registro y Ajustes.
- Etapas: Chispa 4 ... Caos 64 ticks, y 3 Custom editables por modo.

## Compilar
Sube a GitHub: el workflow `build.yml` compila para GD 2.2081 con Geode 5.11.2.
